# Worked example

Two fabricated entries and the weekly review they produce.
It exists so you can see the output shape before trusting the system, and so the rubric has something concrete to be judged against.

Nothing here is real, and no run ever reads this folder.
Every stage contract lists `_system/worked-example/` under "Do NOT load".
